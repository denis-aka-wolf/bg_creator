# Генератор фонового изображения города

`bg.py` процедурно создаёт дальний слой параллакса: бесшовный по горизонтали городской силуэт на фоне закатного неба. Изображение включает солнце, облака, дымку и текстуру неба.

## Требования

- Python
- NumPy
- OpenCV (`opencv-python`)
- Pillow

Установите зависимости в то же окружение Python, из которого будете запускать скрипт:

```powershell
python -m pip install numpy opencv-python Pillow
```

Если запускаете Python по полному пути, например `C:\Python315\python.exe`, используйте его и для установки:

```powershell
& 'C:\Python315\python.exe' -m pip install numpy opencv-python Pillow
```

## Запуск

Из папки проекта выполните:

```powershell
python bg.py
```

Или укажите полный путь к интерпретатору:

```powershell
& 'C:\Python315\python.exe' '.\bg.py'
```

Генерация занимает некоторое время; на проверенной конфигурации она заняла около 34 секунд. Во время работы скрипт может не выводить промежуточный статус. По завершении он напечатает `saved (600, 1800, 3)`.

## Результат

Скрипт сохраняет `bg_far_city.png` в текущую рабочую папку. Размер изображения — **1800 × 600 пикселей**, формат — PNG, цветовой режим — RGB.

Случайные текстуры создаются с фиксированными начальными значениями генератора, поэтому результат воспроизводим при одинаковых версиях библиотек. Для изменения размера результата отредактируйте `W` и `H` в начале `bg.py`; `S` задаёт масштаб внутреннего рендеринга и сглаживания.
